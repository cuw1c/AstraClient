# PixelForge для Android

Это исходный проект Android-приложения, использующий встроенный WebView и редактор текстур из `app/src/main/assets/index.html`.

## Сборка APK прямо с телефона
1. Создай новый публичный или приватный репозиторий на GitHub.
2. Распакуй архив и загрузи **содержимое папки PixelForgeAndroid** в корень репозитория (включая скрытую папку `.github`).
3. Открой вкладку **Actions** и выбери **Build PixelForge APK**.
4. Нажми **Run workflow** (или дождись завершения запуска после загрузки файлов).
5. Открой завершённый запуск, прокрути до **Artifacts** и скачай `PixelForge-debug-APK`.
6. Распакуй скачанный ZIP на телефоне. Установи `app-debug.apk`. Android может попросить разрешить установку приложений из используемого браузера/файлового менеджера.

## Возможности
- Размеры текстуры 16×16, 32×32, 64×64, 128×128
- Кисть, ластик, заливка, пипетка, сетка
- Импорт изображений через системный выбор файла
- Экспорт PNG через системное окно сохранения

Это debug APK для личного тестирования, не подписанный релиз для Google Play.
